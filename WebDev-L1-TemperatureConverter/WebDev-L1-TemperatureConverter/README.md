# OASIS INFOBYTE — Web Development & Designing
## Level 1 · Task 3: Temperature Converter Website

A responsive temperature conversion tool built with HTML5, CSS3, and vanilla JavaScript. It converts Celsius, Fahrenheit, and Kelvin and displays all three results together.

## Features
- Numeric temperature input and unit dropdown
- Convert button with readable result cards
- Validation for empty or invalid values
- Absolute-zero validation with a user-friendly message
- Celsius, Fahrenheit, and Kelvin conversion formulas
- Responsive desktop and mobile layout
- Quick-reference formulas
- Accessible form labels and live error/result announcements

## Files
- `index.html` — structure and form
- `styles.css` — styling and responsive layout
- `script.js` — conversion formulas, validation, and result rendering

## Run locally
1. Extract the ZIP archive.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use VS Code Live Server.
4. Test with values such as `0 °C`, `32 °F`, and `273.15 K`.

No package installation is required. Google Fonts need an internet connection; the converter logic runs locally in the browser.

## Conversion formulas
- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9
- Kelvin = Celsius + 273.15
